Audit Toolkit
created by Ritesh Punyani

Audit Toolkit adds a small library of formulas (=AT.___()) for cleaning, parsing and flagging data, plus a fuzzy name/ID matching wizard - all customisable from one plain Excel sheet, and all computed locally in your workbook. Nothing is uploaded anywhere.

Fuzzy Match

Match two lists of names (vendors against a watchlist, duplicate customer records, related-party checks) even when spelling, word order or legal suffixes differ.

Workpaper functions

Nine formulas for text cleanup, name parsing, keyword flagging and date parsing. Type =AT. in any cell and Excel's own tooltip explains each one as you type.

Settings

Keyword lists, character maps and other defaults live on one visible "AT Settings" sheet you can edit directly - no hidden dialog.

New to the toolkit? Open the Match wizard and click Load sample data on the first step to see it work before trying your own data.

Settings

Every customisable default used by the functions and wizards above lives on one sheet named AT Settings - plain Excel tables you can edit directly. No reinstall, no dialog, no code.

TableDefaultUsed by
Keyword listcash, personal, adjustment, write-off, advance, urgent=AT.KEYWORDFLAG()
Lookalike-character mapO→0, I→1, l→1, S→5, B→8, Z→2=AT.NORMALISECHARS()
Legal-suffix ignore listPvt, Ltd, LLC, GmbH, Trading, Inc...Fuzzy Match wizard

To use your own list instead of the default, pass the Settings sheet range directly as the function's optional second argument, e.g. =AT.KEYWORDFLAG(A2,'AT Settings'!$B$4:$B$9). The function still works perfectly with no second argument at all - the Settings sheet is there for when you want to change something, never a requirement.
