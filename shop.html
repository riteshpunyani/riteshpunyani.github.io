🔐 Before You Run — Macro Enable & Security Guide

Step 1 — Unblock the file (Windows security)

  1. After downloading, do not open the file yet.
  2. In Windows Explorer, right-click the .xlsm file.
  3. Select Properties.
  4. At the bottom, tick "Unblock" → click OK.
  5. Now open the file normally.

⚠️ If you see: "This file came from another computer and might be blocked to help protect this computer" — follow the Unblock steps above before enabling macros.

Step 2 — Enable macros in Excel

  1. When the file opens, click the yellow banner: "Enable Content".
  2. If no banner appears, go to: File → Options → Trust Center → Trust Center Settings → Macro Settings.
  3. Select "Enable all macros" (you can reset this after use).
  4. Alternatively, save the file to a Trusted Location so you are never prompted again.

Running the macro

  • Press Alt+F8 → select the macro → click Run.
  • Or use the keyboard shortcut listed on the Instructions sheet inside the file.
